# Плейлист мероприятия

Откройте StagePlaylist.sln в Visual Studio. F5 — запуск; Ctrl+Shift+B — сборка. Для конструктора формы откройте Form1.cs → «Просмотреть конструктор».

Шаблон: Приложение Windows Forms (C#, .NET), целевая платформа .NET 10.
Нужна рабочая нагрузка Visual Studio «Разработка классических приложений .NET».

Готовое приложение: bin/Release/net10.0-windows/StagePlaylist.exe. Для запуска необходим .NET Desktop Runtime 10.

Данные хранятся в одномерном массиве и восстанавливаются при новом запуске. Повторы разрешены. Удаление выполняется по выделению слева.
